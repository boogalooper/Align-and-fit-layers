# Align and fit layers

Скрипт для **Adobe Photoshop**, который автоматически подбирает фотографии к рамкам, масштабирует и позиционирует их так, чтобы объект корректно располагался внутри кадра, а сама фотография полностью перекрывала рамку.

Подходит для пакетной раскладки портретов и групповых фотографий по нескольким рамкам, а также для работы с уже созданными clipping-группами.

## 🚀 Основные возможности

* Автоматическое определение границ людей или работа по границам всего слоя.
* Подбор фотографий к рамкам по пропорциям; в режиме Python дополнительно учитывается примерное количество лиц.
* Поддержка нескольких рамок с помощью **цветовых меток слоёв Photoshop**.
* Работа с уже созданными **clipping mask**: каждый слой сохраняет связь со своей рамкой.
* Fallback-режим: один нижний выбранный слой можно использовать как общую рамку для остальных.
* Отдельные настройки отступов для вертикальных и горизонтальных рамок.
* Настройки сохраняются между запусками и могут записываться в **Photoshop Action**.

## 🛠 Системные требования

### Photoshop

Скрипт рассчитан на Adobe Photoshop под Windows. Доступные способы определения объекта зависят от версии Photoshop: если какая-либо функция недоступна, соответствующий режим просто не отображается в списке.

### Python — необязательно

Для основного режима **Python** используется отдельная приватная среда. Системный Python устанавливать не нужно: установщик не изменяет существующие версии Python и не добавляет ничего в PATH.

Без Python скрипт продолжает работать через возможности Photoshop или в режиме **Границы слоя**.

## 📥 Установка

### 1. Распакуйте архив

Полностью распакуйте архив в обычную папку. Не запускайте установщик непосредственно из ZIP.

### 2. Установите Python-модуль — рекомендуется

Запустите:

`install_runtime.bat`

В обычной ситуации выберите **1 — Normal secure mode** и дождитесь сообщения об успешной установке.

Если антивирус Kaspersky перехватывает HTTPS и обычная установка не проходит, повторите установку и выберите режим совместимости **2**.

Python, библиотеки и модели будут установлены отдельно в:

`%LOCALAPPDATA%\AlignFitRuntime`

Если установщик сообщает, что Python-сервер уже запущен, закройте Photoshop либо дождитесь автоматического завершения сервера после периода простоя и повторите установку.

### 3. Скопируйте скрипт в Photoshop

Из папки **Photoshop files** скопируйте в папку скриптов Photoshop:

* `Align and fit layers.jsx`
* папку `lib` вместе с `align-fit-api.pyw`

Обычный путь:

`C:\Program Files\Adobe\Adobe Photoshop [версия]\Presets\Scripts\`

После копирования перезапустите Photoshop.

Скрипт появится в меню:

**File → Scripts → Align and fit layers**

> Если Python-модуль не установлен или недоступен, скрипт запускается без ошибки — пункт Python просто не появляется в списке режимов.

## 🕹 Как пользоваться

Обычно вы работаете с двумя типами слоёв:

* **слои с фотографиями** — их нужно выделить перед запуском;
* **слои-рамки** — определяют конечное положение и размер фотографии.

Скрипт сам выбирает способ работы в зависимости от структуры выделенных слоёв и наличия рамок.

### Вариант 1. Несколько фотографий и несколько рамок

Это основной сценарий.

1. Назначьте фотографиям цветовые метки Photoshop.
2. Назначьте рамкам соответствующие цветовые метки.
3. Выделите **только фотографии**, которые нужно разместить.
4. Запустите **Align and fit layers**.

Фотография сопоставляется только с рамкой того же цвета. Если рамок одного цвета несколько, скрипт выбирает наиболее подходящее соответствие по пропорциям. В режиме Python дополнительно учитывается примерное количество лиц: небольшие группы предпочтительно попадают в меньшие рамки, большие — в большие.

Количество рамок каждого цвета желательно делать равным количеству фотографий с такой же меткой.

### Вариант 2. Все фотографии уже находятся в clipping mask

Если **все выделенные слои уже clipped**, цветовые метки для выбора рамок не используются.

Скрипт определяет настоящую base-рамку каждого слоя и выравнивает фотографию именно относительно неё. В одном запуске можно выделить слои, принадлежащие разным clipping-группам; несколько фотографий могут быть clipped к одной и той же рамке.

Существующие clipping-связи сохраняются.

### Вариант 3. Одна общая рамка — fallback

Этот режим удобен, когда нужно подогнать несколько фотографий к одному эталонному слою без цветовой разметки.

1. Выделите будущую рамку и фотографии.
2. **Рамка должна быть самым нижним из выделенных слоёв.**
3. Запустите скрипт.

Fallback включается автоматически, когда подходящих рамок с цветовыми метками нет или их явно недостаточно — менее половины от необходимого количества.

Самый нижний выбранный слой становится общей рамкой и сам не изменяется. Остальные выбранные слои выравниваются относительно него.

Нижний слой не должен уже находиться в clipping mask. В этом случае скрипт остановится, чтобы не изменить структуру документа неоднозначным образом.

### Если часть выбранных слоёв clipped, а часть нет

Такой набор обрабатывается как обычный: существующий clipping не определяет рамку автоматически. Скрипт сначала проверяет цветовые метки и количество подходящих рамок, а при их явной нехватке может перейти в fallback.

### Если не хватает только нескольких рамок

Если подходящих рамок достаточно для большинства фотографий, но одной или нескольких всё же не хватает, скрипт покажет предупреждение.

* **Продолжить** — фотографии, для которых найдены рамки, будут обработаны; остальные останутся в исходной позиции.
* **Остановить** — документ останется без частично выполненного выравнивания.

## 🎯 Режимы определения границ

В верхней части окна можно выбрать, что считать объектом внутри фотографии.

### Python

Рекомендуемый режим, если модуль установлен. Быстро анализирует уменьшенную копию изображения, определяет границы группы людей и примерное количество лиц. Количество лиц дополнительно помогает распределять фотографии между рамками разного размера.

Если Python доступен, этот режим выбирается по умолчанию.

### autoCutout — on device

Использует **Select Subject** самого Photoshop и выполняет анализ локально на компьютере. Обычно быстрее облачного режима, но границы объекта могут определяться менее точно. Количество лиц не учитывается.

### autoCutout — in cloud

Использует облачный **Select Subject** Photoshop. Обычно медленнее Device и требует интернет, но чаще точнее определяет границы объекта. Количество лиц не учитывается.

### Границы слоя

Детекция объекта не выполняется. Скрипт использует границы всего слоя, совмещает центр слоя с центром рамки и пропорционально масштабирует фотографию так, чтобы она гарантированно полностью перекрывала рамку.

Настройки отступов в этом режиме не используются.

---

## ↔️ Отступы объекта

Для режимов **Python**, **autoCutout — on device** и **autoCutout — in cloud** можно задать желаемый запас между найденным объектом и краями рамки.

Настройки задаются отдельно для:

* вертикальных рамок;
* горизонтальных рамок;
* верхнего края;
* нижнего края;
* боковых краёв.

Значения указываются в процентах от размера рамки. Скрипт учитывает реальное свободное место в исходной фотографии и не пытается создать отступ там, где для него недостаточно изображения.

## 🎬 Использование в Photoshop Action

Скрипт можно записать в Action вместе с выбранным режимом и настройками отступов.

1. Начните запись нового Action.
2. Запустите **Align and fit layers**.
3. Выберите нужные настройки и выполните скрипт.
4. Остановите запись Action.

При обычном воспроизведении используются сохранённые в Action настройки без дополнительного окна.

Если в панели Actions включить показ диалога для этого шага, перед выполнением появится окно настроек — их можно изменить для конкретного запуска.

---

## 💡 Особенности работы

* **Python необязателен.** Если он недоступен, скрипт автоматически предлагает только доступные режимы.
* **Настройки запоминаются** между обычными запусками Photoshop.
* **Python-сервер запускается автоматически** при необходимости и завершается после периода простоя.
* **Исходные слои не растрируются для анализа.** Временные преобразования используются только для измерения и затем отменяются.
* **Временные изображения удаляются автоматически.**
* Для рамок и фотографий в обычном режиме используйте одинаковые **цветовые метки Photoshop** — это основной способ указать, какие слои относятся друг к другу.
* Если результат нужно отменить, достаточно обычного **Undo** Photoshop: основное выравнивание записывается одним шагом истории.

## 🗑 Удаление

Чтобы удалить скрипт, удалите из папки Photoshop Scripts:

* `Align and fit layers.jsx`
* `lib\align-fit-api.pyw`

Если Python-режим больше не нужен, после закрытия Photoshop можно также удалить папку:

`%LOCALAPPDATA%\AlignFitRuntime`
