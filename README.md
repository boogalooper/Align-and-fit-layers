# Align and fit layers

**Align and fit layers** — скрипт для Adobe Photoshop, который автоматически размещает фотографии по рамкам: выбирает подходящую рамку, масштабирует фотографию и корректирует её положение.

Скрипт подходит как для раскладки нескольких фотографий по нескольким рамкам, так и для случаев, когда фотографии уже связаны с рамками через обтравочные маски.

## Основные возможности

- автоматическое определение границ человека или группы людей;
- подбор фотографий к рамкам по цветовым меткам и пропорциям;
- опциональный учёт количества лиц при подборе рамок в режиме Python;
- работа с несколькими рамками за один запуск;
- работа с уже созданными обтравочными масками;
- использование нижнего слоя как общей рамки для выравнивания без создания обтравочных масок;
- отдельные отступы для вертикальных и горизонтальных рамок;
- сохранение настроек и запись их в операции Photoshop.

---

## Установка

### 1. Распакуйте архив

Полностью распакуйте архив в обычную папку. Не запускайте установщик прямо из ZIP-файла.

### 2. Установите дополнительный модуль Python

Это рекомендуется сделать один раз перед первым использованием.

Запустите:

`install_runtime.bat`

В большинстве случаев выберите:

`1 — Normal secure mode`

и дождитесь сообщения об успешной установке.

Если на компьютере установлен Kaspersky и обычная установка завершается ошибкой HTTPS, повторите установку и выберите режим совместимости `2`.

Системный Python устанавливать не требуется. Скрипт использует собственную изолированную среду и не меняет уже установленные версии Python.

Без Python скрипт тоже работает, но некоторые способы определения объекта будут недоступны.

### 3. Установите скрипт в Photoshop

Из папки **Photoshop files** скопируйте в папку скриптов Photoshop:

- `Align and fit layers.jsx`
- папку `lib`

Обычно папка скриптов находится здесь:

`C:\Program Files\Adobe\Adobe Photoshop [версия]\Presets\Scripts\`

После копирования перезапустите Photoshop.

Скрипт появится в меню:

**File → Scripts → Align and fit layers**

## Быстрый старт

Для обычной работы с несколькими рамками:

1. Назначьте фотографии и соответствующим им рамкам одинаковые цветовые метки Photoshop.
2. Выделите только слои с фотографиями.
3. Запустите **Align and fit layers**.
4. Выберите способ определения объекта и нажмите **Выполнить**.

Скрипт сопоставит фотографии только с рамками того же цвета, выберет наиболее подходящее соответствие и разместит фотографии по рамкам.

---

## Как скрипт выбирает рамку

Перед запуском важно правильно выделить слои. Дальнейшее поведение зависит от ситуации:

| Ситуация | Что выделить | Как выбирается рамка |
| --- | --- | --- |
| Несколько фотографий и несколько рамок | Только фотографии | По одинаковым цветовым меткам |
| Все выбранные фотографии уже имеют обтравочные маски | Только фотографии | Для каждой фотографии используется её существующая рамка |
| Нужно подогнать несколько фотографий к одной рамке | Рамку и фотографии | Самый нижний выбранный слой используется только как общая рамка для выравнивания |
| Часть выбранных фотографий уже имеет обтравочные маски, а часть нет | Все нужные фотографии | Используются цветовые метки, как при обычной работе |

Ниже каждый вариант описан подробнее.

---

## Несколько фотографий и несколько рамок

Это основной режим работы.

Каждая фотография должна иметь ту же цветовую метку Photoshop, что и предназначенная для неё рамка.

Например, если в документе есть три синие фотографии и три синие рамки, скрипт распределит фотографии только между этими тремя рамками. Если рамки различаются по форме и размеру, скрипт постарается подобрать наиболее подходящие пары.

В режиме Python можно дополнительно включить опцию **«Учитывать количество лиц при подборе рамок»**. Она помогает различать, например, одиночные портреты и групповые кадры, если рамки одного цвета отличаются по размеру.

**Рамки выделять не нужно.** Выделяются только фотографии.

Лучший вариант — когда количество фотографий каждого цвета совпадает с количеством рамок того же цвета.

### Если одной или нескольких рамок не хватает

Если подходящих рамок не хватает совсем немного, скрипт покажет предупреждение.

Вы сможете выбрать:

- **Продолжить** — фотографии, для которых рамки найдены, будут размещены; остальные останутся на своих местах;
- **Остановить** — выравнивание не будет выполнено.

Такой случай обычно означает, что у одной из рамок или фотографий забыта цветовая метка.

---

## Фотографии уже находятся в обтравочных масках

Если **все выделенные фотографии уже связаны с рамками через обтравочные маски**, цветовые метки не используются.

Скрипт определяет рамку каждой фотографии по существующей структуре документа и выравнивает фотографию относительно неё.

Можно одновременно выделить фотографии из нескольких разных обтравочных групп. Также несколько фотографий могут использовать одну и ту же рамку.

Существующие связи с рамками сохраняются.

---

## Одна общая рамка для нескольких фотографий

Этот вариант удобен, когда несколько фотографий нужно подогнать к одному и тому же слою без цветовой разметки.

1. Выделите рамку и все фотографии, которые нужно подогнать.
2. Убедитесь, что рамка находится **ниже всех остальных выбранных слоёв**.
3. Запустите скрипт.

Если подходящих внешних рамок по цветовым меткам нет или их явно слишком мало, скрипт автоматически использует самый нижний выбранный слой как общую рамку.

Сам слой-рамка не изменяется. Остальные выбранные слои только перемещаются и масштабируются относительно него. **Новые обтравочные маски в этом режиме не создаются, и порядок слоёв не меняется.**

**Важно:** нижний выбранный слой не должен сам находиться в обтравочной маске. В таком случае скрипт остановится, чтобы не изменить структуру документа непредсказуемым образом.

Если вы хотите гарантированно использовать этот вариант, проще всего не назначать выбранным фотографиям цветовые метки, связанные с другими рамками документа.

---

## Если часть фотографий уже имеет обтравочные маски

Если обтравочная маска есть только у части выделенных фотографий, скрипт не использует существующие связи как указание на рамку.

Такой набор обрабатывается как обычный: сначала проверяются цветовые метки и ищутся соответствующие рамки.

Если подходящих рамок практически нет, может быть использован самый нижний выбранный слой как общая рамка.

---

## Способы определения объекта

В верхней части окна выбирается, какие границы фотографии использовать при выравнивании.

### Python

Рекомендуемый вариант после установки дополнительного модуля.

Скрипт определяет границы человека или группы людей и примерное количество лиц.

Под списком режимов появляется дополнительная опция **«Учитывать количество лиц при подборе рамок»**. Она включена по умолчанию.

- Если опция включена, при распределении фотографий между рамками одного цвета учитывается не только форма кадра, но и примерное количество лиц. Это особенно полезно, когда среди кадров есть и портреты, и группы людей.
- Если опцию выключить, количество лиц не влияет на выбор рамки. Скрипт подбирает соответствие прежде всего по пропорциям кадра и рамки.

Эта опция влияет только на **выбор подходящей рамки**. Способ определения границ человека остаётся тем же.

Если Python доступен, этот вариант выбирается по умолчанию.

### Локальное определение средствами Photoshop

В списке этот вариант называется `autoCutout — on device`.

Photoshop определяет объект непосредственно на компьютере. Интернет не требуется. Обычно этот способ работает быстрее облачного, но иногда менее точно определяет границы объекта.

Количество лиц при таком анализе не учитывается.

### Облачное определение средствами Photoshop

В списке этот вариант называется `autoCutout — in cloud`.

Photoshop определяет объект с помощью облачной обработки. Требуется интернет. Обычно этот способ работает медленнее локального, но может точнее определять сложные границы.

Количество лиц не учитывается.

### Границы слоя

Объект внутри фотографии не определяется.

Скрипт использует весь слой целиком, совмещает его центр с центром рамки и масштабирует слой так, чтобы он полностью перекрывал рамку.

Этот вариант удобен, когда положение человека внутри фотографии уже подготовлено заранее или определение объекта не требуется.

Настройки отступов в этом режиме не используются.

## Отступы от рамки

Для режимов, в которых определяется человек или группа людей, можно настроить свободное пространство между найденным объектом и краями рамки.

Отдельные значения задаются для вертикальных и горизонтальных рамок:

- сверху;
- снизу;
- по бокам.

Значения указываются в процентах от размера рамки.

Например, увеличение верхнего отступа оставляет больше свободного пространства над головой, а увеличение бокового — больше пространства слева и справа от объекта.

Скрипт учитывает реальные границы фотографии: если за пределами объекта недостаточно изображения, требуемый отступ не будет создан искусственно.

---

## Использование в операциях Photoshop

Настройки скрипта можно записать в операцию Photoshop и затем применять без повторного выбора параметров.

1. Начните запись новой операции.
2. Запустите **Align and fit layers**.
3. Выберите нужные параметры и выполните скрипт.
4. Остановите запись.

При обычном воспроизведении будут использованы параметры, сохранённые в операции, включая выбранный способ определения объекта, отступы и настройку учёта количества лиц.

Если для шага скрипта включить показ диалогового окна, перед выполнением можно будет изменить настройки.

---

## Полезно знать

- Настройки сохраняются между обычными запусками Photoshop.
- Дополнительный модуль Python запускается автоматически только при необходимости.
- Исходные фотографии не растрируются для анализа.
- Временные файлы удаляются автоматически.
- Основное выравнивание записывается одним шагом истории Photoshop и может быть отменено обычной командой **Отменить**.
- Если Python недоступен, скрипт просто скрывает этот вариант и предлагает доступные способы работы.

---

## Удаление

Чтобы удалить скрипт, удалите из папки Photoshop Scripts:

- `Align and fit layers.jsx`
- папку `lib`, если она использовалась только этим скриптом.

Если дополнительный модуль Python больше не нужен, после закрытия Photoshop можно удалить папку:

`%LOCALAPPDATA%\AlignFitRuntime`
